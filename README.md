# Лапичка – приют за животни

ASP.NET Core MVC (.NET 8) + Identity + EF Core (SQL Server LocalDB).

## Стартиране
1. Отвори `Lapichka.csproj` във Visual Studio (File → Open → Project).
2. Натисни F5. Базата `LapichkaDb` се създава сама при първо стартиране.

## Начален администратор
- Имейл: `admin@lapichka.bg`
- Парола: `Admin123`

## Готово към момента
- Регистрация и вход (имейл + парола)
- Валидация: уникален имейл, парола (мин. 8 символа, главна, малка, цифра), потвърждение на парола, български телефон
- Роли: Administrator, Employee, RegisteredUser (нов потребител = RegisteredUser)
- Паролите се пазят хеширани
- Таблици в базата: `Species` (видове), `Animals`, `AdoptionRequests`, `VetProcedures`, `VolunteerApplications`
  - уникален индекс: една активна (нова) заявка за осиновяване на потребител за едно животно
  - уникален индекс: една кандидатура за доброволец със статус „нова“ на потребител
  - видовете не могат да се изтрият, ако има животни от тях
- Начални данни: видове Куче, Котка, Заек и 5 примерни животни с процедури
- Списък с животни, търсещи дом (търсене по име/вид, филтър по вид, страниране по 6)
- Детайлна страница за животно с ваксинации и ветеринарни процедури
- Валидация: възраст 0–30, дата на процедура не по-късно от днес

> Ако имаш стара база `LapichkaDb` (без новите таблици), при стартиране в Development тя се пресъздава автоматично.

## Следва
- Добавяне/редакция на животни и качване на снимки (служител), изтриване (администратор)
- Управление на видове (администратор)
- Заявки за осиновяване и кандидатури за доброволци
- Въвеждане на ветеринарни процедури
- Управление на потребители (администратор)
- Редакция на профил и смяна на парола
